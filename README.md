# 🐾 Питомец Финни

Мобильное приложение для Android — игровой сервис, который помогает детям 7–11 лет освоить базовые финансовые навыки. Ребёнок заботится о виртуальном питомце и учится распределять игровую валюту: от его решений зависят настроение и развитие Финни.

> Проект создан по ТЗ Департамента финансов города Москвы (2026). Приложение бесплатное и просветительское.

## Как это работает

1. Ребёнок создаёт питомца и получает стартовый бюджет в игровой валюте.
2. Перед началом игрового периода распределяет бюджет: **обязательные расходы**, **желаемое**, **накопления**.
3. Зарабатывает валюту за задания, делает покупки, копит на финансовую цель.
4. После периода сравнивает план с фактом и видит, как это повлияло на питомца.

## Возможности

- Создание и настройка питомца (внешний вид, имя)
- Главный экран: баланс, накопления, цель, состояние питомца, активное задание
- Планирование бюджета с контролем остатка
- Магазин с обязательными и необязательными покупками
- Финансовые цели и накопления
- Задания-мини-сценарии по трём темам: бюджет, сбережения, платежи и покупки
- Рост питомца (3+ стадии) с объяснением причин изменений
- Раздел для взрослого (защита от ребёнка, прогресс, сброс профиля)
- Демонстрационный режим для проверки без ожидания календарных сроков
- Сохранение прогресса после перезапуска, работа без интернета

## Безопасность

Без регистрации, рекламы, реальных платежей и сбора персональных данных. Игровая валюта не имеет реальной стоимости. Все данные хранятся только на устройстве.

## Быстрый старт

1. Склонируйте репозиторий и откройте проект в Android Studio.
2. Соберите APK одним из способов:
   - **В Android Studio:** `Build` → `Generate App Bundles or APKs` → `Generate APKs`.
   - **В командной строке:** перейдите в корень проекта и выполните:

     ```bash
     ./gradlew assembleDebug
     ```

     APK обычно появляется в `app/build/outputs/apk/debug/`.
3. Установите APK на Android-устройство (8.0+).
